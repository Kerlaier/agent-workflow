# 质检报告模板

> 命名：`质检报告-YYYYMMDD-主题.md`
> 铁律：**报告写完不改成品** —— 只写「问题 + 证据 + 建议」，动手改的是 owner。
> 目的：**防漏馅 / 防翻车** —— 把每一句「声称」对应到可核实的原始材料。

---

## 一、问题（按危险度排序）

| # | 被检查的说法 / 产物 | 风险点（会被怎么追问） | 危险度 |
|---|---|---|---|
| 1 |  |  | 🔴 最高 |
| 2 |  |  | 🟠 高 |
| 3 |  |  | 🟡 中 |
| 4 |  |  | 🟢 低 |

> 危险度判据：**被当场追问的概率 × 答不上来的代价**。

---

## 二、证据（每条都必须能回溯）

> 只写**能查到的原文**：文件 + **章节名 + 原文片段**。
> **行号只作辅助**（会漂移）；**引用旧记录前先确认当前状态**（它可能已被改过）。

1. **<文件名>** → §<章节名>：
   - 原文片段：「……」
   - 由此得出的结论：……

2. ……
