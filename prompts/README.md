# prompts/

这里放**实际在用的提示词**，不是示范。全部去掉了身份与具体数据，`<尖括号>` 是需要你替换的占位。

| 文件 | 给谁用 | 什么时候用 |
|---|---|---|
| `01-规划型-启动提示词.md` | 第三个 agent（长期规划 + 情报） | **每个新会话开头**，让它进入状态 |
| `02-教学型-出材料要求.md` | 教学 agent（讲义 / 代码） | 派讲义、派练习任务时 |
| `03-工程型-发布前自检.md` | 工程 agent（文档 / 发布） | **公开发布之前**，逐条过 |
| `04-质检派单模板.md` | 规划 agent → 其他 agent | 需要"没人验收的产出"被核对时 |

> **为什么这些提示词值得留档**：它们不是"更好的说话方式"，每一条都是**某次翻车之后补的**。
> 哪一条对应哪次翻车，写在每个文件里。
