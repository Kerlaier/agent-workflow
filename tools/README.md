## 它要干什么

读仓库里的 markdown 文件，生成两份摘要：**待办** + **最近更改**。

## 输入

- 仓库内的 markdown（`protocol/`、`docs/`，以及使用者自己的全局事实文件等）。
- 路径通过命令行参数传入，**不要写死**。

## 输出

1. **待办摘要**：收集所有 `- [ ]` 行，**按来源文件分组**。
2. **最近更改摘要**：从各文件的「更新记录」段落取最近 N 条，格式为 `YYYY-MM-DD HH:MM｜谁｜改了什么`。
3. 输出形式：先打到 **stdout**（Markdown 文本）。

## 硬约束

- **只读**：不许写回任何被读的源文件。
- **不联网、不调用模型 API**。
- 中文输出。
- **时间戳只做展示，不做排序依据** —— 同一天的多条按文件内出现顺序排列（时间戳可能缺失或不一致）。
- 找不到「更新记录」段落的文件，跳过并在末尾列一行提示，**不要报错退出**。

## 建议用法

```bash
python summarize.py --files "protocol/*.md" "docs/*.md" --recent 10
```
